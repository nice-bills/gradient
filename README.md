# Gradient

A free university for AI, curated. Live: https://nice-bills.github.io/gradient/

- Five courses in order (GRD 101 to 380), 44 hand-checked lectures and readings.
- A bulletin of new lectures from 40 graded sources (S/A/B), with Shorts removed.
- A lecture hall that plays a course back to back (N next, P previous, D done, Esc).
- Progress saved as a transcript in your browser. No accounts, no tracking.

Sources live in `sources.py` and courses in `paths.py`. Rebuild the bulletin with `python3 build_feed.py` (it writes `app/public/data.json`).
